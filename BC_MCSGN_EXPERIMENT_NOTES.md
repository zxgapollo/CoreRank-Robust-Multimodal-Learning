## Implemented Milestone

The current milestone builds a fixed SCM benchmark and an end-to-end first-pass training pipeline:

1. Generate fixed train/validation/test datasets from a stable latent SCM.
2. Save ID and OOD test splits in a reusable `.npz` artifact.
3. Train a discriminative warmup model that outputs a biased proto-state.
4. Train BC-MCSGN with latent `Z`, graph-induced clean state `S`, modality residuals `U_i`, modality decoders, and a bias transition from `S,U` to the proto-state.
5. Evaluate every method on the same fixed train/ID/OOD splits.

## SCM

Latent variables use the six-factor nonlinear SCM from the design:

- `Z1`, `Z2`, `Z4` are exogenous.
- `Z3 = tanh(1.2 Z1 - 0.8 Z2) + 0.2 eps3`.
- `Z5 = sin(Z3) + 0.5 Z4 + 0.2 eps5`.
- `Z6 = tanh(Z5) + 0.2 eps6`.

The clean masked disease state is:

```text
S = w_S * Z,    w_S = [0, 0, 1, 0, 1, 1]
```

The label mechanism is invariant:

```text
P(Y=1 | S) = sigmoid(1.5 Z3 + 1.2 Z5 - 0.8 Z6)
```

The true latent graph and true modality masks are saved with the fixed dataset.

## Modalities

The four modalities are all treated uniformly as `X_i`.

```text
Gamma_1 = {Z3, Z5}
Gamma_2 = {Z2, Z5, Z6}
Gamma_3 = {Z1, Z4}
Gamma_4 = {Z3, Z6}
```

Each modality is generated by a fixed random MLP from its latent footprint plus additive and multiplicative observation residual effects:

```text
X_i = f_i(Z_Gamma_i) + A_i U_i + (B_i U_i) * f_i(Z_Gamma_i) + noise
```

The synthetic biased proto-state is:

```text
S_tilde = S + Delta(U_1, ..., U_m) + noise
```

## Splits

The fixed dataset contains:

- `train`
- `val`
- `test_id`
- `test_ood_a`: one modality has attenuated same-sign label-related residual strength
- `test_ood_b`: one modality has an independent protocol/site mean shift in `U_i`
- `test_ood_c`: one modality has amplified residual variance
- `test_ood_d`: one modality has shifted missingness/quality base rate with the same label direction

The latent graph, structural mechanisms, and `p(Y|S)` are invariant across all splits. Only the observation layer `U_i` and missingness shift.
No OOD split flips `Y`, changes the sign of the label mechanism, or uses a negative label-related residual coefficient.

## Models

Implemented methods:

- `concat`: direct discriminative baseline over concatenated modalities.
- `warmup`: multimodal warmup model with modality dropout, proto-state consistency, and optional synthetic proto teacher.
- `bc_mcsgn`: latent correction model with `q(Z,U|X,S_tilde)`, graph-induced state, modality reconstruction, bias transition, graph/mask penalties, and label head using only the clean state representation.

The current first-pass code supports two diagnostic modes:

- Main unsupervised pilot: learned graph/masks and warmup proto.
- Anchor diagnostic pilot: fixed graph/masks and synthetic-only state/delta anchors. This is not a deployable method result; it checks the SCM upper bound and identifies whether failures come from unsupervised state/residual separation.

## Outputs

Each run writes:

- `data/bc_mcsgn_seed*.npz`
- `dataset_diagnostics.json`
- `config.json`
- `train_config.json`
- `checkpoints/*.pt`
- `metrics.csv`
- `summary.json`
- `figures/*.png` unless `--no-plots` is used

Core metrics include ID/OOD AUC, NLL, state recovery, bias transition recovery, graph/mask recovery, and shortcut sensitivity proxy.

## Current Status

The earlier A100 runs under `outputs/bc_mcsgn_a100_pilot` and `outputs/bc_mcsgn_a100_anchor_pilot` used an invalid sign-reversal `test_ood_b` and should not be used as results.
The corrected generator keeps the latent SCM and label mechanism invariant and only changes modality-level observation residual or quality distributions.
